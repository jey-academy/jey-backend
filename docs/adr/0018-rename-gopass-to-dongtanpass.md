# ADR-0018: 모듈 이름을 dongtanpass로 변경

- 상태: 채택
- 날짜: 2026-10-10

## 배경
할인 패스 기능의 모듈 이름은 `gopass`였다. 기능 이름 "동탄고 패스"를 줄인 이름인데, 줄임말이라 코드나 API 경로만 봐서는 어떤 기능인지 바로 알기 어렵다.
모듈 이름에서 API 경로(ADR-0013), 테이블 접두사, 에러 코드 접두사(ADR-0014), 이벤트 이름(ADR-0016), 커밋 scope가 모두 파생된다. 이 이름들은 코드, DB, 로그, 프론트 곳곳에서 계속 읽히므로 한눈에 파악되는 이름이 낫다. 테이블이나 공개 API가 생긴 뒤에는 바꾸기 어렵고, 지금은 모듈에 선언 파일만 있다.

## 선택지
1. `gopass` 유지 — 짧음 / 기능 이름과 바로 연결되지 않는 줄임말
2. `dongtanpass` — 기능 이름이 그대로 보임 / 5글자 길어짐
3. `dongtangopass` 또는 `dongtanhspass` — 고등학교라는 뜻까지 담음 / 길고 한눈에 읽히지 않음

## 결정
2번을 채택한다.

- 모듈 이름은 `dongtanpass`다. 파생되는 이름도 함께 바꾼다.

| 종류 | 이전 | 이후 |
|---|---|---|
| 패키지 | `com.jey.gopass` | `com.jey.dongtanpass` |
| API 경로 | `/api/v1/gopass/…` | `/api/v1/dongtanpass/…` |
| 테이블 접두사 | `gopass_` | `dongtanpass_` |
| 에러 코드 접두사 | `GOPASS_` | `DONGTANPASS_` |
| 이벤트 이름 | `gopass.{사건}` | `dongtanpass.{사건}` |
| 커밋 scope | `gopass` | `dongtanpass` |

- 한글 표기는 "동탄고 패스"로 띄어 쓴다.
- 앞선 ADR(0012, 0013, 0014)의 본문은 새 이름으로 고친다. ADR은 현재 규칙을 설명하는 문서이기 때문이다. 이름을 바꿨다는 사실은 이 문서에 남긴다.
- 지난 PR, 이슈, 커밋 메시지는 고치지 않는다.

## 근거
- `dongtanpass`는 "동탄"과 "패스"가 그대로 보여서, 처음 보는 사람도 API 경로나 테이블 이름만으로 어떤 기능인지 알 수 있다.
- 한글도 "동탄고 패스"로 띄어 쓰면 "동탄고"와 "패스"가 나뉘어 더 쉽게 읽힌다.
- 이름을 바꾸는 비용은 지금이 가장 낮다. 고칠 것은 패키지 선언 2개, 테스트의 모듈 이름 검사, 문서뿐이다.

## 포기한 것
- 영문 이름에 고등학교라는 뜻은 담기지 않는다.
- API 경로, 테이블 이름, 에러 코드가 5글자씩 길어진다.
- 지난 PR과 커밋 메시지에는 `gopass`가 남아 검색할 때 두 이름을 모두 찾아야 한다.

## 재검토 조건
- 동탄고가 아닌 다른 학교나 기관의 패스를 다루게 될 때 (학교를 가리지 않는 이름으로 일반화)
