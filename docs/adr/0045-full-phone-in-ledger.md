# ADR-0045: 장부(구글 시트)의 부모 전화는 전체 번호로 쓴다

- 상태: 채택
- 날짜: 2026-10-21

## 배경
앱은 전체 전화번호를 따로 정한 창구로만 내주고, 볼 때마다 감사 로그와 횟수 한도를 건다(ADR-0026). 다른 응답·로그·이벤트에는 가린 번호만 나간다.

결제를 장부에 쓸 때(ADR-0044) "부모 전화" 칸이 있다. 이 칸은 결제 대행사 파일을 만들 때 그대로 복사되어 결제 안내가 그 번호로 간다. 지금도 직원이 전체 번호를 손으로 적는다.

## 선택지
1. 전체 번호를 쓴다 — 장부가 지금처럼 쓰인다 / 앱 밖(구글)에 전체 번호가 놓인다
2. 가린 번호를 쓴다 — 앱 밖으로 전체 번호가 나가지 않는다 / 결제 대행사 파일을 만들 때 직원이 번호를 다시 찾아 적어야 한다(자동 기록의 뜻이 없어진다)
3. 칸을 비운다 — 2번과 같다

## 결정
1번으로 한다. ADR-0026의 예외다.

- 전체 번호는 장부의 "부모 전화" 칸에만 쓴다. 로그, 예외 문구, 감사 로그, 앱의 반영 기록에는 싣지 않는다.
- 쓸 때마다 감사 로그를 남긴다(대상 학생, 지점, 탭, 행 — 번호는 없다).
- 서비스 계정은 프로젝트 역할이 없고, 장부 파일만 편집자로 공유받는다. 다른 파일·폴더는 공유하지 않는다.
- 키는 운영 비밀 저장소에만 두고 코드·채팅·메신저에 붙이지 않는다.
- 번호는 대표 연락처(어머니 → 먼저 연결된 학부모 → 학생 본인)다.

## 근거
- 장부는 이미 전체 번호가 적힌 문서이고 직원끼리 공유해 쓴다. 앱이 쓰는 것으로 새로 노출되는 사람은 없다.
- 결제 안내가 그 번호로 간다. 가리면 사람이 다시 적어야 하고, 그때 잘못 적을 위험이 생긴다.

## 받아들인 위험
- 서비스 계정 키가 새면 그 키로 공유받은 장부 전체(전체 번호 포함)를 읽고 고칠 수 있다. 공유 범위를 장부 파일로 줄이고, 키를 비밀 저장소에만 둬 위험을 줄였을 뿐 없애지는 못했다. 새면 키를 지우고 새로 만든다.
- 장부의 번호는 구글의 권한 체계를 따른다. 장부를 공유받은 사람은 앱의 한도와 감사 로그 없이 번호를 본다(지금과 같다).

## 재검토 조건
- 결제 안내를 앱이 직접 보내게 될 때 → 장부의 번호 칸을 가리거나 뺀다
- 장부를 공유받는 사람이 늘거나 외부로 나갈 때 → 가린 번호로 바꾸고 대행사 파일은 앱이 만든다
